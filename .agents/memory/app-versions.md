---
name: Basic and Full versions
description: Why BUYME uses one set of shop data across its simplified and full interfaces
---

Basic and Full are two views of the same shop, not separate accounts or datasets. Hide advanced navigation and QR generation in Basic without deleting the seller's catalog, saved bills, or existing payment profiles.

**Why:** Basic is meant for a tutorial and quick counter use, and the seller can switch versions at any time. Separating the data would make a version switch appear to lose work.

**How to apply:** When adding features to either version, preserve shared sales/catalog history and decide explicitly whether the feature should be shown in Basic. Keep payment receipts accurate even when Basic does not generate or display a QR.
